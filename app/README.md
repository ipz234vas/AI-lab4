# SmartNotify: запуск HTML-застосунку

Залежності: Python 3.10+, пакет `openai` та запущена Ollama з принаймні однією локальною моделлю.

```powershell
python -m pip install "openai>=1.99.0,<3"
ollama pull qwen3.5:2b-q4_K_M
python .\app\server.py
```

Відкрити **http://127.0.0.1:8765**. Якщо порт зайнятий: `python .\app\server.py --port 8766`.

1. Оберіть встановлену модель зі списку Ollama та контекст (1024–8192, типовий 4096); натисніть **Підключити** для прогріву. Зміна моделі/контексту потребує нового підключення. Технічні псевдоніми моделей для різного `num_ctx` створюються локально, базові ваги не змінюються.
2. Введіть **Відправник** і **Повідомлення**, натисніть **Аналізувати**.
3. Для чернетки натисніть **Згенерувати** або увімкніть **Автоматично створювати чернетку**. Чернетка редагується, але застосунок ніде її не надсилає.
4. Налаштування: температура аналізу 0–1, температура чернетки 0–1 (незалежні), максимум токенів 64–320, початково 220; Seed — порожнє поле генерує нове випадкове ціле число для кожного запиту, введене число фіксує seed. Після зміни параметрів старі результати зберігаються; нова генерація виконується тільки кнопкою.
5. **Метрики / JSON** показують час, вхідні та вихідні токени й фактично використаний seed кожного етапу.

Якщо Ollama не відповідає, запустіть `ollama serve` або перевірте, чи вона вже запущена. Застосунок обробляє таймаути й некоректні JSON-відповіді.

```powershell
python -m unittest discover -s .\app\tests -v
node .\app\tests\test_ui.js   # необов'язково
```

Примітка: сервер використовує офіційний Python SDK `openai` з локальним `base_url` для інференсу та прогріву і `/api/tags`, `/api/create` для списку моделей та конфігурації контексту. Він працює лише на `127.0.0.1`. Реальні результати моделі не підміняються правилами чи шаблонами Python. У критичних ситуаціях не покладайтеся на чернетки ШІ.
