# Лабораторна №4 — локальні мовні моделі / SmartNotify

**SmartNotify** — навчальний вебзастосунок для локальної моделі Ollama: визначає терміновість повідомлення (`low`, `medium`, `high`, `critical`) та за бажанням пропонує редаговану чернетку відповіді. Жодних хмарних API й автоматичного надсилання повідомлень.

## Запуск застосунку

Потрібні **Python 3.10+**, **Ollama**, локально встановлена модель, наприклад:

```powershell
ollama pull qwen3.5:2b-q4_K_M
python .\app\server.py
```

Відкрити `http://127.0.0.1:8765`. У вебінтерфейсі: вибрати модель і контекст → **Підключити** (прогрів) → ввести текст → **Аналізувати** → за потреби **Згенерувати**. Температури класифікації та чернетки регулюються окремо, результати не губляться від зміни налаштувань. Докладніше — `app/README.md`.

```powershell
python -m unittest discover -s .\app\tests -v
python -m unittest discover -s .\experiments\tests -v
node .\app\tests\test_ui.js  # необов'язково, якщо є Node.js
```

## Обрана конфігурація й результати

- **Рантайм:** Ollama, HTTP API; застосунок використовує OpenAI-сумісний `/v1/chat/completions`.
- **Модель за замовчуванням:** `qwen3.5:2b-q4_K_M`, частково розміщується на CPU через обмежені 3 GB VRAM. За потреби модель перемикається в інтерфейсі.
- **Базові параметри порівнюваних запусків:** `temperature=0`, `seed=1`, `num_ctx=4096`, `max_tokens=220`, `think=false`. Температура 0 обрана для відтворюваності, **не доведена як оптимальна за точністю**.
- **10 однакових повідомлень:** 0.6B — 5/10, 1.7B — 7/10, Qwen3.5-2B — 8/10, 4B — 9/10 правильних категорій. Всі мають семантичні помилки в окремих чернетках. 4B точніша на цій малій вибірці, але суттєво повільніша; 2B обрана як практичний компроміс.
- **Оптимізація промптів:** компактний англійський класифікатор Qwen3.5-2B — також 8/10, але витрачає менше вхідних токенів; останній генератор чернеток скорочує середній час A/B-прогону, проте все ще помиляється в окремих ролях/обіцянках. Це дослідний, не виробничо надійний застосунок.

Результати зберігаються в `bench_results.csv` та `experiments/results/`. **Внутрішні мітки й шляхи в історичних JSON залишені такими, якими були на момент запуску** — вони відображають походження експериментів; перейменовані тільки файли архіву. Відповідність назв промптів описано в `experiments/README.md`.
